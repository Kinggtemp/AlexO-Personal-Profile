Road Accident Data Analysis

This project was completed as part of a university group assignment, focusing on analysing UK road accident data to identify patterns and factors influencing accident severity.

My Role

I was responsible for data cleaning, exploratory data analysis, and creating visualisations using SPSS. I also contributed to analysing relationships between variables and supporting the development of a decision tree model.

Tools Used

  • Python
  • SPSS
  • GitLab

Key Insights

Accidents were more frequent during peak traffic hours, and weather conditions showed a relationship with accident severity.
